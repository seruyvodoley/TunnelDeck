# TunnelDeck network health — краткая инструкция

## Проверить VPS

1. Откройте **Diagnostics**.
2. Нажмите **Run VPS Network Health**.
3. Проверьте время проверки и строки результата.

Проверка безопасна: TunnelDeck только читает состояние VPS, делает один DNS-запрос и один короткий HTTPS-запрос. Она проверяет:

- основной маршрут VPS;
- куда ведёт lookup адреса российского назначения с меткой `0x67`;
- DNS и TLS/HTTPS с самого VPS;
- состояние службы Xray и listener `8443`;
- Docker-контейнер Caddy `ma-alice-https`;
- доступный объём RAM и диска.

Запуски попадают в таблицу диагностики и локальную историю приложения. `Passed` означает, что прошла именно указанная проверка. Например, успешный lookup подтверждает выбор маршрута ядром, но не отправку реального пользовательского пакета.

## Что эта проверка не подтверждает

Это серверная диагностика. Она не подтверждает домашнюю маршрутизацию через Xiaomi, политику отдельного устройства, отсутствие DNS/IPv6-утечки или активную клиентскую сессию VLESS + REALITY. Для домашней сети используйте **DNS Path Test** и актуальную **Topology**, а окончательное подтверждение маршрута требует проверки с тестового домашнего устройства.

Индикатор Xray показывает состояние server unit и TCP listener. Это не синоним успешной передачи данных REALITY. Путь Caddy проверяется как контейнер, поскольку на текущем VPS Caddy не является host systemd-службой.

## Если проверка показывает проблему

- **VPS DNS / HTTPS:** сравните с отдельными строками DNS и TLS; не перезапускайте туннели из-за одной ошибки DNS.
- **RU policy route lookup:** проверьте отметку и таблицу в Topology. Проверка не меняет маршрут.
- **Xray:** service должен быть active/running и иметь listener на `8443`; клиентский тест REALITY выполняется отдельно.
- **Caddy:** смотрите контейнер `ma-alice-https`, а не `caddy.service` на хосте.
- **Unknown:** TunnelDeck не получил достаточного доказательства; это не зелёный статус и не автоматическое подтверждение исправности.

Все проверки в этой панели read-only. Управление маршрутизацией и автоматическое восстановление не включаются этой кнопкой.
